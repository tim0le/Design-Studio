## What this is

A code-driven slide editor built on **Marp**:

- Write slides in plain Markdown — separated by `---`
- Style is in a single `.css` theme file
- Render to PDF, PPTX (image), PPTX (editable, beta), PNG, JPG, or HTML
- Edit slides directly in the browser or via a Claude Code agent session
